# Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment focuses on solving practical problems using TypeScript and Object-Oriented Programming (OOP). It covers optional and default parameters, union types, type narrowing, readonly tuples, generic functions, interfaces, and array operations. It also includes class inheritance, access modifiers, and asynchronous programming with Promises. Additionally, two technical blog posts explain Type Aliases vs Interface and Access Modifiers in TypeScript.

## Problem Solutions

**1. Multiply Value:** Implemented an optional multiplier with a default value while handling zero correctly. <br>
**2. Process Input:** Used union types and type narrowing to process strings, numbers, and booleans. <br>
**3. Format Coordinate:** Used a readonly tuple to format location details without modifying the original values. <br>
**4. Concatenate Arrays:** Applied generics and rest parameters to combine multiple arrays of the same type. <br>
**5. Popular Courses:** Used an interface and array filtering to find published courses based on the minimum student count. <br>
**6. Pluck Values:** Applied generic constraints and `keyof` to extract specific property values from objects. <br>
**7. Employee and Manager:** Implemented classes, inheritance, and access modifiers to manage employee and manager information. <br>
**8. Validate Age Async:** Used Promises and `setTimeout` to handle age validation with asynchronous success and error responses. <br>
